# Diya Patel — Software Developer Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS and JavaScript, focused on software development, AI/ML and real-world projects.

## Highlights
- Software Developer + AI/ML positioning
- Black-shirt professional profile photo
- Animated hero/orbit cards and developer terminal section
- Circular technology icons for frontend, backend, databases and developer tools
- Three deployed projects with project preview images and live demo links
- Smart Inventory and Secure User project images updated with the latest previews
- YouTube demo cards for Smart Inventory and Secure User Management
- Separate SSIP — AI Fire Safety Drone showcase
- Separate real-world Hospital Online Appointment System project (in progress)
- Focused practice section with WanderLust — Airbnb Clone and IoT Fire & Smoke Safety System
- Education timeline from Std. 1–12 through B.Tech IT
- Internship, experience and certificate sections
- Contact form configured through FormSubmit
